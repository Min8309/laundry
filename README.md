# 아직 따뜻한 세탁소

빌드가 필요 없는 반응형 문학 웹사이트 첫 화면입니다.

## 실행
`dist` 폴더를 정적 웹 서버로 열어 주세요. 예: `python3 -m http.server 8000 --directory dist`

## 파일
- `dist/index.html`: 한국어 콘텐츠와 구조
- `dist/styles.css`: 데스크톱/모바일 화면, 키보드 포커스, 동작 줄이기 설정
- `dist/app.js`: 이야기 준비 안내 대화상자
- `dist/assets/laundry-dusk.webp`: 참고 이미지의 재료감과 분위기를 반영한 AI 생성 골목 이미지

`아버지의 양복` 본문은 제공되지 않아 준비 중 안내만 표시합니다. 실제 본문을 추가할 때 대화상자 또는 별도 읽기 페이지로 연결하면 됩니다. 외부 추적기, 회원 가입, 자동 재생 소리가 없습니다.

독립적인 정적 호스팅에는 `dist`의 파일을 올리면 됩니다. Sites용 `.openai/hosting.json`은 다른 호스팅에 필요하지 않습니다.

## 글꼴
제목과 서정적인 본문은 사용자 참고 이미지의 **부크크 명조**를 사용합니다. 웹폰트는 jsDelivr에서 로드되며, 네트워크 차단 시 명조 계열 시스템 글꼴로 대체됩니다. 제작사 안내: https://bookk.co.kr/font . 글꼴 파일 자체는 이 소스에 재배포하지 않습니다.

## 골목길 오프닝
기존 사진을 그대로 이용한 CSS 카메라 이동과 빛·타이틀 전환이며 동영상 생성물은 아닙니다.
- 0–3초: 어두운 골목을 따라 이동
- 3–6초: 세탁소의 따뜻한 불빛을 발견
- 6–8.3초: 문 쪽으로 다가감
- 8.3–10초: 첫 화면으로 부드럽게 전환하며 제목 등장
- 탭 세션의 첫 방문에만 자동 재생. `골목길 다시 걷기`로 재생 가능.
- 건너뛰기, Escape, 메뉴 이동, 휠/터치 스크롤로 즉시 종료.
- 운영체제의 동작 줄이기 설정을 존중하고 자동 재생 소리는 없음.

## 은은하게 숨 쉬는 빛 버튼
주요 이동, 오프닝 제어, 음악, 이야기 카드, 대화상자 버튼에 둥근 형태와 따뜻한 황금빛 확산광을 적용했습니다. 기존 부크크 명조를 유지합니다. 호버·키보드 포커스에서 0.5초 동안 빛이 나타나고 2.6초 주기로 밝기가 부드럽게 오르내립니다. 모바일은 누르는 동안 즉각적인 피드백을 제공하고, 동작 줄이기 설정에서는 움직이지 않는 빛과 명확한 포커스 표시만 사용합니다. 버튼의 터치 높이는 최소 44px입니다.

## 배경 음악
사용자가 제공한 `leberch-last-see-297847.mp3`를 `dist/assets/background-music.mp3`로 포함했습니다. MP3, 스테레오 48kHz, 약 1분 38.5초입니다. 첫 로드는 무음이며 `음악 켜기`를 직접 누르면 25% 음량으로 반복 재생합니다. 오른쪽 하단에서 켜기·끄기만 제공하며 다른 탭으로 전환하면 일시 정지합니다. 자동으로 다시 소리를 켜지 않습니다. 음량 슬라이더는 없으며 실제 음량은 기기의 음량 설정으로 조절할 수 있습니다.
