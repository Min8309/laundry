# 아직 따뜻한 세탁소

빌드가 필요 없는 반응형 문학 웹사이트 첫 화면입니다.

## 실행
`dist` 폴더를 정적 웹 서버로 열어 주세요. 예: `python3 -m http.server 8000 --directory dist`

## 파일
- `dist/index.html`: 한국어 콘텐츠와 구조
- `dist/styles.css`: 데스크톱/모바일 화면, 키보드 포커스, 동작 줄이기 설정
- `dist/app.js`: 이야기 준비 안내 대화상자
- `dist/assets/laundry-dusk.webp`: 참고 이미지의 재료감과 분위기를 반영한 AI 생성 골목 이미지

`아버지의 양복` 본문은 제공되지 않아 준비 중 안내만 표시합니다. 실제 본문을 추가할 때 대화상자 또는 별도 읽기 페이지로 연결하면 됩니다. 외부 추적기, 회원 가입, 자동 재생 소리가 없습니다.

독립적인 정적 호스팅에는 `dist`의 파일을 올리면 됩니다. Sites용 `.openai/hosting.json`은 다른 호스팅에 필요하지 않습니다.

## 글꼴
제목과 서정적인 본문은 사용자 참고 이미지의 **부크크 명조**를 사용합니다. 웹폰트는 jsDelivr에서 로드되며, 네트워크 차단 시 명조 계열 시스템 글꼴로 대체됩니다. 제작사 안내: https://bookk.co.kr/font . 글꼴 파일 자체는 이 소스에 재배포하지 않습니다.

## 골목길 오프닝
기존 사진을 그대로 이용한 CSS 카메라 이동과 빛·타이틀 전환이며 동영상 생성물은 아닙니다.
- 0–3초: 어두운 골목을 따라 이동
- 3–6초: 세탁소의 따뜻한 불빛을 발견
- 6–8.3초: 문 쪽으로 다가감
- 8.3–10초: 첫 화면으로 부드럽게 전환하며 제목 등장
- 탭 세션의 첫 방문에만 자동 재생. `골목길 다시 걷기`로 재생 가능.
- 건너뛰기, Escape, 메뉴 이동, 휠/터치 스크롤로 즉시 종료.
- 운영체제의 동작 줄이기 설정을 존중하고 자동 재생 소리는 없음.

## 은은하게 숨 쉬는 빛 버튼
주요 이동, 오프닝 제어, 음악, 이야기 카드, 대화상자 버튼에 둥근 형태와 따뜻한 황금빛 확산광을 적용했습니다. 기존 부크크 명조를 유지합니다. 호버·키보드 포커스에서 0.5초 동안 빛이 나타나고 2.6초 주기로 밝기가 부드럽게 오르내립니다. 모바일은 누르는 동안 즉각적인 피드백을 제공하고, 동작 줄이기 설정에서는 움직이지 않는 빛과 명확한 포커스 표시만 사용합니다. 버튼의 터치 높이는 최소 44px입니다.

## 배경 음악
사용자가 제공한 `leberch-last-see-297847.mp3`를 `dist/assets/background-music.mp3`로 포함했습니다. MP3, 스테레오 48kHz, 약 1분 38.5초입니다. 첫 로드는 무음이며 `음악 켜기`를 직접 누르면 25% 음량으로 반복 재생합니다. 오른쪽 하단에서 켜기·끄기만 제공하며 다른 탭으로 전환하면 일시 정지합니다. 자동으로 다시 소리를 켜지 않습니다. 음량 슬라이더는 없으며 실제 음량은 기기의 음량 설정으로 조절할 수 있습니다.

이 파일은 사용자가 제공한 자료입니다. 공개 재배포 권리는 별도로 검증하지 않았습니다. 사이트를 공개하거나 소스를 공개 저장소에 올리기 전에 음악의 사용·재배포 조건을 확인해 주세요.

### 낭독과 함께 듣기
음악과 1장 낭독은 각각 버튼으로 켜며 동시에 재생할 수 있습니다. 음악은 평소 25%, 낭독 중 7% 음량으로 약 0.4초에 걸쳐 부드럽게 전환됩니다. 낭독 일시정지·종료·오류 또는 다른 장으로 이동하면 켜져 있는 음악만 원래 음량으로 돌아옵니다. 음악을 직접 끈 경우 낭독이 끝나도 다시 켜지지 않습니다. 음악의 반복 재생, 낭독 재생 위치, 탭 숨김·페이지 이탈 시 정지 동작은 유지합니다.

iOS의 미디어 요소 `volume` 제약을 고려해 음악 버튼을 누를 때 Web Audio `GainNode`를 만들고 `AudioContext.resume()`과 `play()`를 같은 사용자 제스처 안에서 호출합니다. Web Audio가 없는 브라우저에서는 미디어 요소 음량 조절로 대체하며, 이 경우 기기에 따라 음량 조절이 제한될 수 있습니다. 오디오 파일은 같은 출처에 둬야 합니다.

검증: Playwright와 Chromium이 설치된 환경에서 `node tests/audio.cjs`를 실행합니다 (`CHROMIUM_PATH`로 실행 파일 변경 가능). 테스트는 로컬 서버를 직접 열고 실제 MP3로 동시 재생, 감쇠·복원, 수동 끄기, 역순 시작, 종료 후 재생, 음악 반복, 장 이동·뒤로 가기·포커스, 키보드·ARIA 상태, 페이지 이탈·탭 숨김, 재생 실패·대기 중 취소를 확인합니다. 데스크톱 및 모바일 크기/터치 에뮬레이션에서 Web Audio와 대체 경로를 검사합니다.

실제 iPhone/iPad Safari와 Android 기기에서 청취 검증은 별도로 필요합니다. Chromium 모바일 에뮬레이션은 iOS의 오디오 정책, 기기 음량·무음 모드, 잠금 화면·전화 수신·Bluetooth 전환을 재현하지 않으며, 자동 테스트는 실제 청감이나 스크린 리더 음성 출력을 검증하지 않습니다.
## 세 번째 이야기 · 아이의 유치원복

세 번째 카드에서 `#kindergarten-uniform`으로 이동해 전문을 읽습니다. 사용자가 제공한 수정본 51개 문단을 보존하고, 접수 전에 입학식이 닷새 뒤임을 필담으로 확인하는 짧은 대화만 추가했습니다. 카드 소개도 현재 이야기 내용에 맞췄습니다. 한국어 본문은 `dist/index.html`의 `#uniform-reader`, 같은 순서의 영어 번역은 `dist/i18n.js`의 `UNIFORM_EN`에 있습니다. 기존 언어 선택, 읽기 화면 스타일, 브라우저 뒤로/앞으로 이동을 사용합니다.

### 추후 낭독 파일 연결

`#uniform-narration-toggle`은 기존 낭독 버튼과 같은 스타일의 비활성 버튼입니다. 현재는 한·영으로 음성 준비 중임을 표시하며, 음성 소스나 재생 이벤트를 연결하지 않았습니다.

사용자가 음성을 제공하면:
- 파일을 `dist/assets/`에 추가하고 `#uniform-reader .narration-player` 안에 고유 ID의 `<audio preload="none">`으로 연결합니다.
- `#uniform-narration-toggle`의 `disabled`를 제거하고 `aria-controls`, `aria-pressed`, 재생/일시정지 및 오류 상태를 연결합니다. 준비 중 문구도 두 언어로 갱신합니다.
- `dist/app.js`의 기존 낭독 동작처럼 직접 누른 경우에만 재생하고, 다른 낭독과 동시에 재생되지 않도록 합니다. 배경음악은 위의 감쇠·복원 동작을 공유하도록 연결합니다. 다른 이야기로 이동하거나 탭을 떠나면 일시정지합니다.

현재 음성은 추가하거나 생성하지 않았습니다.

## 두 번째 이야기 · 할머니의 니트

2번 카드에서 `#grandmothers-cardigan`으로 연결합니다. 사용자 최종 수정본의 67개 문단, 장면 전환 두 곳, 강조 세 곳을 보존했습니다. 꽃무늬 천의 글씨 발견 장면만 “그곳에는 글씨가 없었다.”에서 “처음에는 글씨가 보이지 않았다.”로 수정했습니다. 본문은 `dist/index.html`의 `#cardigan-reader`, 문단별 영어 번역은 `dist/i18n.js`의 `CARDIGAN_EN`입니다. 영어 번역은 문장 중간의 강조도 유지하도록 안전하게 이스케이프한 HTML로 저장합니다.

`#cardigan-narration-toggle`은 음성 준비 중인 비활성 버튼입니다. 제공된 할머니 음원은 다운로드가 완료되지 않아 연결하지 않았으며, 다른 이야기의 음성을 대신 사용하지 않습니다. 파일 접근 후 실제 형식·길이·재생을 확인하고, 위 낭독 연결 지침에 따라 연결해야 합니다.
